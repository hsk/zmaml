# 9. ZMA の書き方を読む・書く

hlang のアセンブラは、HRA! さんの Z80/R800 クロスアセンブラ [ZMA](https://github.com/hra1129/zma) の書き方を読めます。逆アセンブラと `--zma` の出力は、ZMA の書き方で出ます。ZMA で書かれたソースを hlang で組み立てることも、hlang の出力を ZMA で組み立てることもできる、というのが狙いです。

> **確かめたことと、確かめていないこと。** ZMA の取扱説明書（[zma_doc.md](https://github.com/hra1129/zma/blob/main/zma_doc.md)）の例は、手で確かめた機械語と一致します（[test/t_zma.ml](../test/t_zma.ml)）。**本物の ZMA での突き合わせは、まだしていません。** 特に、hlang の出力のラベル名（`main.loop.39.body` のように `.` を含む）を ZMA が受け付けるかは、確かめていません。

## 使い方

```sh
hlc file.zma                 # 組み立てて file.bin を作る（.zma .asm .z80 .a80）
hlc file.zma --org 0x4000    # 開始番地（ファイルの先頭に org があればそちら）
hlc file.zma -DMODE=1 -Iinc  # 定数を決める。INCLUDE を探す所を足す

hlc file.hl --zma            # hlang のコンパイル結果を ZMA の書き方で表示
hlc file.rom --dis           # 機械語を ZMA の書き方で逆アセンブル（.rom は 0x4000 から、他は 0 から）
hlc file.bin --dis --org 0x100 --db 0x120-0x140   # この範囲は命令でなく defb にする
```

逆アセンブルは、行末のコメントに「番地: 機械語」を付けます。飛び先にはラベル（`L4015`）を付け、MSX の BIOS の呼び出しとポートには名前を添えます。

```asm
L4015:
    ld a,[hl]                   ; 4015: 7e
    or a                        ; 4016: b7
    ret z                       ; 4017: c8
    call 0xa2                   ; 4018: cd a2 00  BIOS chput
    inc hl                      ; 401b: 23
    jp L4015                    ; 401c: c3 15 40
```

命令とデータは機械語だけでは区別がつかないので、データの表は `--db` で教えます。教えないと、表も命令として読みます（読み直して組み立てれば、元のバイト列には戻ります）。

## 読めるもの

| 分類 | 内容 |
| --- | --- |
| 行 | `name:`（局所）、`name::`（大域）、`name = 式`（局所の定数）、`name := 式`（大域の定数）、`; コメント`。ラベルと命令は同じ行に書ける。`name equ 式` と `name: equ 式` も読む |
| 数 | `1234`、`1_234`、`0x1f`、`$1f`、`1fh`（A〜F で始まるときは `0DEADh`）、`0b1010`、`0777`（**先頭が 0 なら 8 進数**）、`'c'` |
| 式 | `+ - * / % << >> < > <= >= == != & ^ \| && \|\|` と、単項の `+ - ! ~`、括弧。優先順位は ZMA の表のとおり。`$` はその行の先頭の番地。ラベルも使える |
| メモリ | `[hl]` `[ix+3]` `[ix]`（`ix+0`）`[0x1234]` `[c]`。`jp hl` / `jp [hl]` はレジスタの値へ飛ぶ |
| データ | `defb`（文字列も可）、`defw`、`defd`、`space 個数[, 埋める値]`、`align 境界` |
| 展開 | `名前 macro 引数, ...` … `endm`、`repeat 変数, 回数` … `endr`、`if 式` … `elseif` … `else` … `endif`、`scope 名前` … `endscope`、`include "ファイル"`、`binary_link "ファイル"`、`message "..."`、`error "..."` |
| 先頭 | `org 番地`（ファイルの先頭に 1 つだけ） |

`db` `dw` `ds` `defm` `byte` `word` も読みます（ZMA にはありませんが、Zilog 系の書き方との行き来のためです）。命令は大文字でも小文字でも構いません。

## ZMA との違い

- **`( )` で全体を囲んだオペランドは、メモリ参照とみなします。** ZMA では `( )` は式のまとまりだけで、メモリは `[ ]` ですが、hlang 自身の出力（`--asm`）は Zilog の書き方（`ld a,(hl)`）なので、両方読めるようにしてあります。そのため `ld a,(1+2)` は、ZMA では定数 3、ここではメモリ参照です。`ld a,(1+2)*3` のように括弧が全体を囲まなければ、ZMA と同じです。
- **`defs` は、ZMA の `-DEFS` を付けた形**（`defs 個数[, 埋める値]`）で読みます。ZMA の既定は「文字列式をその場に置く」ですが、他のアセンブラと同じ形の方が一般的なので、そちらに寄せました。
- **IF と REPEAT の判断は、その場で値が決まる式だけ**です（数、`=` で決めた定数、`-D` の値）。ラベルが入る条件は、エラーにします。ZMA の「ラベルの値に応じて最も小さくなる並べ方を探す」仕組みは、まだありません。
- **`org` は先頭に 1 つだけ**です。途中の `org`（ROM から RAM へ写すコードなど）には未対応です。
- **マクロの中のラベルは、呼ぶたびに作り直しません。** ZMA の説明書にも決まりがないので、同じマクロを 2 回呼ぶなら、中のラベルが重なってエラーになります。必要なら `scope` で囲んでください。

## まだ読まないもの

次は、行に出てくるとエラー（「ZMA の … には未対応」）になります。

- 文字列の式（`"ab" * 3`、`"ab" + 3`）と、マクロの文字列引数（`@D`）
- `chg_char_set`、`mapping_char`（文字コードの割り当て）
- `link` / `endl`、`add_include_path`（`-I` で代わりにできる）
- `$$`（ファイルの中の位置）、`code_address`、`file_address`
- R800 の命令（`mulub`、`muluw`）、IXH / IXL / IYH / IYL
- `-hex`（Intel HEX の出力）、ROM ヘッダの種類

## 作り

[src/zma.ml](../src/zma.ml) 1 つで、2 段の関数に分けています。どちらも、前の段の結果だけから次を作ります。

1. **展開（`expand`）**：行のリストを受け取り、行のリストを返します。マクロや REPEAT は、名前を文字として置き換えるだけです（ZMA のマクロも文字の置き換えです）。置き換える表（`vars`）は、マクロの引数や REPEAT の変数を入れる、入れ子のたびに足す表で、`repeat I, I+1` の内側の `I` が外側の `I` を隠すのも、この表の順番だけで決まります。`scope` と REPEAT の 1 回ぶんは、中の局所のラベルに他と重ならない名前（`loop@3`）を付けます。
2. **読み込み（`parse_line`）**：展開が済んだ 1 行を、`Asm.line` にします。式は優先順位の表を下から上へたどる再帰下降で、数だけの式はその場で計算します。ラベルの入る式は `Asm.e` のまま持ち、アセンブラが 2 回なめる中で値にします。

アセンブラ（[src/asm.ml](../src/asm.ml)）の式には、このために `Bop`（二項演算）、`Uop`（単項演算）、`Here`（`$`）を足しました。コンパイラが出すコードは今までどおり `Num` `Sym` `Add` `Lo` `Hi` だけを使います。

ZMA の書き方で出すのは、`Asm.show ~z:true` の 1 つの引数です（メモリを `[ ]`、定数を `:=`、データを `defb` `defw` `space`）。逆アセンブラ（[src/dis.ml](../src/dis.ml) の `zma`）は、命令を読む `dis` の結果に、ラベルとコメントを付けるだけです。

検証は往復です。hlang の出力（Zilog 形式と ZMA 形式）と、機械語の逆アセンブルの 3 通りを読み直して組み立てると、元の機械語に戻ることを、6 つのプログラム（MSX 5 つと SMS 1 つ）で確かめています。
